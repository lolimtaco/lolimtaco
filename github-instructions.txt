# How to Update Your Portfolio on GitHub

Whenever you make changes to your portfolio files (like adding a YouTube video link to `project-rooms.html` or updating text in `index.html`), follow these steps to publish those changes to your live website:

1. Open your terminal or command prompt.
2. Make sure you are in your portfolio folder. If you aren't, run:
   cd E:\ANTIGRAVITY\Portfolio

3. Add all your modified files to the "staging area" by running:
   git add .

4. Commit your changes with a short message describing what you did:
   git commit -m "Add Project Rooms page and update links"
   (Note: You can change the message inside the quotes to whatever makes sense for your update!)

5. Finally, push your changes to internet:
   git push origin main

6. That's it! Wait about 1-2 minutes, then refresh your live website (https://lolimtaco.github.io/lolimtaco/) to see the changes. If you don't see them right away, try a "hard refresh" by pressing Ctrl + F5 (or Ctrl + Shift + R).

---
Quick Reference Commands:
git add .
git commit -m "Your update message here"
git push origin main
